# Project Documentation

This folder contains current documentation for the Speech-to-SQL project.
Anything copied from the older unstructured workspace has been removed.

## Current Docs

- `project_structure.md` explains the repository layout.
- `pipeline_architecture.md` explains the M1 to M5 pipeline.
- `running_and_verification.md` explains how to run the CLI, dummy DB checks,
  tests, and schema audit.
- `ml_models.md` explains which local ML models exist and when they are used.

## Rule

Docs in this folder should describe the current `apps/`, `src/speech_to_sql/`,
`config/`, `temp_recipe_db/`, and `tests/` layout. Do not add chat transcripts,
old folder dumps, zip notes, or copied legacy project text here.
